このアプリについて

「オリジナルAI」は、作者が自分のためだけに使っている、AIキャラクターとの会話・調べものの記録用アプリです。一般の方への公開・提供はしていません。

Googleアカウントのデータの使い方

  • このメール機能で求める許可は、Gmailを読むだけの許可（gmail.readonly）です。メールの送信・削除・既読にする・ラベルの変更などは行いません。
  • Gmailの読み取り権限自体はアカウント内のメールを対象とします。本アプリでは、利用者本人がアカウントごとに、対象期間・件名のキーワード・送信元・手動選択・全件対象などの読み込み条件と、利用を許可するAIを設定します。検索や一覧表示のために、件名・送信元・日時・メールの抜粋などを取得します。本文の取得やAIへの送信は、設定条件と本人の操作に従います。
  • 読み込んだメールは、本人の操作によって、本人が選んだAIサービスに渡し、仕分け・要約・質問への回答・返信の下書きに使います。
  • 取得したメール本文と、それを使ったAIへの質問・回答は、本アプリのサーバー側で処理し、画面に一時表示します。本アプリの通常の会話履歴・長期記憶・Driveの保存ファイルには記録しません。メール画面を閉じると一時データを消去し、キャラクターへの一時相談表示も画面の切り替えや再読み込みで消えます。本人がコピー・保存した内容は、この削除の対象外です。
  • Googleから受け取る許可の鍵（トークン）、接続アカウントの識別情報・メールアドレス・読み込み条件は、作者が管理するGoogle Apps Scriptのスクリプトプロパティに保管します。トークンはGoogleとの認証・API通信のために使い、AIサービスや公開ページには渡しません。
  • メールをAIへ送る場合は、本人が設定で許可し、その操作で選んだAIサービスに、処理に必要なメール内容や質問を提供します。本アプリは、メールデータを販売・広告目的で利用・提供しません。送信先AIサービス側での保存期間やデータの取り扱いは、そのサービスのAPI規約と本人のアカウント設定に従います。

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

許可の取り消し

アプリの画面でアカウントを外すと、本アプリが保管しているトークンとアカウント設定を削除し、Googleへ許可の取り消しを要求します。通信エラーなどで取り消しに失敗した場合は、画面の案内に従い、Googleアカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」で取り消してください。そこから直接取り消すこともできます。すでにAIへ送った内容や本人が保存した内容の削除は、各サービス側で行ってください。
